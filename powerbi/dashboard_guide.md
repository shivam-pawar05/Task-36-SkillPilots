# Power BI Dashboard Guide
Connect Power BI Desktop to PostgreSQL (`localhost`, database `ecommerce_db`) using Import mode. Load products, categories, inventory, warehouses, orders and order_items. Create relationships using their primary/foreign keys.

Suggested visuals:
- Card: distinct product count
- Card: total inventory quantity
- Card: total sales amount
- Bar chart: products by category
- Donut chart: stock by warehouse
- Table: product, warehouse, quantity and reorder level
- Line chart: sales by order date

DAX measures:
```dax
Total Products = DISTINCTCOUNT(products[product_id])
Total Stock = SUM(inventory[quantity])
Total Sales = SUM(orders[total_amount])
Low Stock Products = CALCULATE(COUNTROWS(inventory), FILTER(inventory, inventory[quantity] <= inventory[reorder_level]))
```
Save the actual report as a `.pbix` from Power BI Desktop; the file is not generated by this source package.
